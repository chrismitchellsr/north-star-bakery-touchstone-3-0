# North Star Bakery — Touchstone 3

A four-page, responsive website revised from Touchstone 2.

## Pages
- `index.html` — home
- `products.html` — breads, pastries, cakes
- `about.html` — bakery story and video
- `contact.html` — inquiry and pre-order form
- `styles.css` — shared mobile-first styles

## Media assets needed
Copy the original North Star Bakery client media ZIP assets into this same folder (or update the HTML paths): `bakery-logo.png`, `bakery-storefront.jpg`, `bakery-feature-small.jpg`, `bakery-feature-large.jpg`, `bakery-bread.jpg`, `bakery-signature-loaf.jpg`, `bakery-welcome.mp3`, `bakery-behind-scenes.mp4`. These assets were not included in the uploaded Word files.

The pre-order form is a front-end demonstration only (`action="#"`); it does not send orders to a server.

## Publish
Upload all files to a public GitHub repository, then enable GitHub Pages from the main branch / root. Insert the repository and live Pages URLs into the design explanation document.
